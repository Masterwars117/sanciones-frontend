Proyecto con:

- Frontend: Nuxt 4 / Vue
- Backend: Django 5
- Base de datos: Oracle XE en Docker

## Estructura
- `backend/`
- `frontend/`

## Requisitos
- Python 3.10
- Node.js
- Docker Desktop
